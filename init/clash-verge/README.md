# Clash Verge 初始化说明

## 工具说明

当前使用 Clash Verge Rev，安装在 `D:\Clash Verge`。

## 当前状态

- 核验日期：2026-09-29
- 当前版本：2.5.6
- 可执行文件：`D:\Clash Verge\clash-verge.exe`
- 官方发布页：https://github.com/clash-verge-rev/clash-verge-rev/releases/latest

## 初始化步骤

1. 从官方发布页下载 Windows x64 安装包。
2. 安装到 `D:\Clash Verge`。
3. 启动后手动恢复订阅和代理设置。
4. 订阅链接、节点和其他敏感配置不得提交到仓库。

`init/setup.ps1` 只检测 Clash Verge 是否存在；缺失时显示官方下载地址，不自动处理敏感配置。
